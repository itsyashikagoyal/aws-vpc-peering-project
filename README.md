# aws-vpc-peering-project
AWS VPC Peering demonstrating private connectivity between two VPCs in another regions

# Project Overview
This project demonstrates how to establish private network connectivity between two Amazon Virtual Private Clouds (VPCs) using AWS VPC Peering. It involves configuring VPCs, subnets, route tables, security groups, and EC2 instances to enable communication between resources in separate virtual networks.

# Key Learnings

- Creating and configuring AWS VPCs and subnets.
- Understanding public and private subnet routing.
- Establishing connectivity using VPC Peering.
- Configuring route tables and security groups.
- Accessing private EC2 instances through a bastion host.
- Troubleshooting network connectivity using ping and SSH.
